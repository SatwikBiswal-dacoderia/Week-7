## 🔄 Understanding While Loops

One of the main goals of these exercises was to understand how **while loops** can be used to execute a block of code repeatedly as long as a given condition remains true.

A `while` loop generally consists of three important parts:

1. **Initialization:** Setting the starting value of a variable.
2. **Condition:** Checking whether the loop should continue.
3. **Update:** Changing the variable so the loop can eventually terminate.

A basic while loop looks like this:

```python
counter = 1

while counter <= 10:
    print(counter)
    counter += 1
```

In this example, the loop prints numbers from 1 to 10. The counter increases after every iteration, and the loop stops when the condition becomes false.

Understanding these parts helps prevent infinite loops and makes it easier to solve problems involving repetition, sequences, and collections of data.
